เริ่มต้นใช้ GitHub ครั้งแรก 🚀

5 ตุลาคม 2567 · เรียนรู้

GitHub คือเว็บไซต์สำหรับเก็บโค้ดและไฟล์ต่าง ๆ แบบออนไลน์ แต่สิ่งที่เจ๋งคือ เราสามารถใช้มันสร้างเว็บไซต์ฟรีได้ด้วย! 🎉

GitHub Pages คืออะไร?

GitHub Pages เป็นบริการฟรีจาก GitHub ที่ให้เราเอาไฟล์ HTML, CSS, JavaScript ขึ้นไปเก็บแล้วมันจะกลายเป็นเว็บไซต์ให้เลย ไม่ต้องจ่ายค่า hosting!

ขั้นตอนที่ทำ

1 สมัครบัญชี GitHub — ใช้อีเมลสมัครได้เลย ฟรี
2 สร้าง Repository — เหมือนโฟลเดอร์สำหรับเก็บไฟล์โปรเจกต์
3 สร้างไฟล์ HTML — เขียนหน้าเว็บแล้วใส่เข้าไป
4 เปิด GitHub Pages — ไปที่ Settings → Pages แล้วเลือก branch
5 ได้เว็บไซต์! — เข้าได้ที่ stolern.github.io/feedback

สิ่งที่ได้เรียนรู้

🔹 ไม่ต้องเก่งโค้ดก็สร้างเว็บได้
