# StoLern Blog 📝

เว็บ Blog ส่วนตัวของ StoLern — บันทึกเรื่องราว ความคิด และสิ่งที่เรียนรู้

🌐 **เว็บไซต์:** [stolern.github.io/feedback](https://stolern.github.io/feedback)

## โครงสร้างไฟล์

```
├── index.html          # หน้าแรก — แสดงบทความทั้งหมด
├── about.html          # หน้าเกี่ยวกับ
└── posts/
    ├── hello-world.html    # โพสต์: สวัสดีชาวโลก
    └── learn-github.html   # โพสต์: เริ่มต้นใช้ GitHub
```

## วิธีเพิ่มบทความใหม่

1. สร้างไฟล์ `.html` ใหม่ในโฟลเดอร์ `posts/`
2. เพิ่มลิงก์ไปที่บทความใหม่ใน `index.html`
